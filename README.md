## About

ryP0 brings independent iOS software and releases together in one clean catalog.

Browse projects, check versions, and access their original sources without searching through multiple repositories.

---

## LiveContainer

> [!TIP]
> **Recommended for LiveContainer users**
>
> Convert **ryP0 to a Shared App** and open it using **LiveContainer 2**.
>
> This keeps **LiveContainer 1** available so apps opened through ryP0 can be sent directly to your primary LiveContainer.

### Setup

1. Open ryP0 settings in LiveContainer
2. Select **Convert to Shared App**
3. Open **LiveContainer 2**
4. Launch ryP0 from there
